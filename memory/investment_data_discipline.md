## 投资分析数据纪律

每次回答投资相关问题（行情、走势、个股分析、辩论、portfolio），必须按以下顺序检查：

1. **先确认当前时间**：调用 current_timestamp(format="datetime") 获取北京时间，标注在回复开头
2. **美股数据必须标注日期**：明确是「X月X日收盘」还是「盘前/盘中」，不能混用。美股收盘 = 北京时间凌晨 4:00，当晚 21:30 开盘
3. **A股数据必须标注实时性**：明确是「今日盘中 14:30」还是「X月X日收盘」
4. **所有数字必须有来源**：现价 = 实时拉取，成交额 = 搜索确认，不能凭记忆或估算
5. **预测必须先检查外生变量**：周末/节后必查地缘政治、美伊局势、油价、重大政策，不能用平时的分析框架套特殊时期

**Why:** 7/10 周五预测周一走势时漏掉了周末美伊冲突升级（霍尔木兹海峡关闭），导致「周一科技反弹」的预测完全错误。7/14 把昨晚盘前数据当成今晚数据，时间搞混。

**How to apply:** 每次回答投资问题前先跑 current_timestamp，在回复第一行标注时间。美股数据标注日期。预测走势前先搜「周末/隔夜重大事件」。
