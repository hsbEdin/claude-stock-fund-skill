## Phase 2 — 计算（严格按此逻辑）

### 股票
```
市值 = shares × 最新收盘价
成本 = shares × cost（如果 shares > 0）或 amount（如果 shares = 0）
浮动盈亏 = 市值 - 成本
盈亏% = (市值 - 成本) / 成本 × 100
```

### 基金（已拉净值，amount ≥ 50000）
```
最新净值 = fund_data 最新一条记录的单位净值
估算份额 = amount / 最新净值（反算）
成本净值 = 基金净值数据中最早一条的净值，或 cost / 估算份额
当前市值 = 估算份额 × 最新净值
浮动盈亏 = 当前市值 - cost
```
注：如果 fund_data 返回为空或失败，降级为「估算」，当前市值 = amount。

### 基金（未拉净值）
```
当前市值 = amount（使用 portfolio.json 中存储的金额）
浮动盈亏 = 当前市值 - cost
```

### 汇总
```
股票总市值 = Σ股票市值
基金总市值 = Σ基金当前市值
总投资资产 = 股票总市值 + 基金总市值 + cash
总成本 = Σ股票成本 + Σ基金amount + cash
总浮动盈亏 = 总投资资产 - 总成本
总盈亏% = 总浮动盈亏 / (总成本 - cash) × 100
```

### 行业集中度
```
按 sector/type 分类，计算各类占比总投资资产
科技相关 = 半导体 + 通信设备 + 半导体封测 + 科技成长(基金) + AI ETF + 科创ETF
周期价值 = 化工 + 电力 + 价值防御
海外 = QDII
均衡 = 均衡混合 + 偏股混合
```

## 重要规则

1. **实时行情必须拉**：对每只有 shares 或 amount 的股票，必须调用 stock_data 获取最新价
2. **基金净值尽力拉**：有 code 的就拉 fund_data(nav)，没有 code 的标注「估算」
3. **盈亏用红色/绿色标注**：亏损标 🔴 前缀，盈利标 🟢 前缀
4. **风险预警逐条计算**，不是模板套话：
   - 科技集中度 = 科技相关资产市值 / 总投资资产
   - 单票占比 > 25% 股票资产 → 警告
   - PE > 50x 的票 → 警告（从最新财务指标中查）
   - 日跌幅 > 5% 的票 → 警告
5. **建议必须有可执行性**：不能只说「注意风险」，要说「XX 股票在 XX 价位减仓多少」
6. **基准对比必须算**：组合收益率 vs 沪深300同期的差值是衡量你能力的唯一客观指标。如果连续3个月跑输基准，说明需要调整策略。
