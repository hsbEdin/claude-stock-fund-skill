## 工作模式

### 模式一：/thesis open <6位代码>

创建一条新的投资论文。分两步：

**Step A — 拉取当前数据：**

调用 current_timestamp(format="date") 获取 TODAY。

并行拉取：
1. stock_data(code="XXX.XX", market_type="cn", start_date=3月前, end_date=TODAY, indicators="macd(12,26,9) rsi(14) kdj(9,3,3) boll(20,2) ma(5) ma(10) ma(20) ma(60)")
2. money_flow(ts_code="XXX.XX", start_date=1月前, end_date=TODAY)
3. company_performance(ts_code="XXX.XX", data_type="indicators", start_date=20250101, end_date=TODAY)
4. finance_news(query="股票名称")

从数据中提取：当前价、PE(TTM)、RSI、MACD状态、主力资金近20日流向、最新季报净利润增速。

**Step B — 引导用户完成第一性原理清单（逐条询问，不可跳过）：**

按以下顺序逐条向用户提问，每问完一条再问下一条：

```
1. 核心论文（一句可证伪的判断）
   例："全球MDI龙头，PE 15.9x远低历史中枢25-30x，RSI极端超卖后高管增持确认底部，6-12月回升至81-91"

2. 证伪条件（2-3个可观测、可度量的条件。只要有一条触发 = 论文失败）
   例：
   - Q2营收同比跌幅 > 5%
   - MDI价格跌破12000元/吨
   - 高管反手减持

3. 入场信息
   - 入场价：____ 元
   - 仓位：____ 手（____ 元）
   - 买入日期：____

4. 止损价：____ 元（最多亏 ____ 元，亏 ____%）

5. 目标价 & 持有期限：____ 元 / ____ 个月

6. 概率分布（三项概率加起来必须 = 100%）
   - 乐观概率 ____%，目标价 ____，收益 ____%
   - 基准概率 ____%，目标价 ____，收益 ____%
   - 悲观概率 ____%，止损价 ____，亏损 ____%

7. 期望值 EV = 乐观%×乐观收益 + 基准%×基准收益 + 悲观%×悲观亏损
```

用户回答完毕后，生成 JSON 记录，写入 `~/.claude/thesis_ledger.json`。

**Step C — 保存并确认：**

生成一个唯一 ID（THESIS-XXX，自增），将所有信息写入 thesis_ledger.json。

向用户展示完整的论文卡片：

```
┌──────────────────────────────────────────┐
│  THESIS-001  万华化学 600309              │
│  创建：2026-06-01  状态：🟢 ACTIVE         │
│                                          │
│  论文：全球MDI龙头PE 15.9x低估...          │
│                                          │
│  入场：¥75.70 × 1手 = ¥7,570              │
│  止损：¥64.00（-15.5%，-¥1,170）          │
│  目标：¥81-91 / 6-12个月                  │
│                                          │
│  概率分布：                               │
│  🟢 乐观 30% → ¥91 (+20.2%)              │
│  🟡 基准 50% → ¥81 (+7.0%)               │
│  🔴 悲观 20% → ¥64 (-15.5%)              │
│                                          │
│  EV = +7.46% ✅（正期望值，可执行）         │
│                                          │
│  证伪条件：                               │
```

### 模式二：/thesis review

读取 `~/.claude/thesis_ledger.json`，列出所有 ACTIVE 状态的论文。

对每一条 ACTIVE 论文：
1. 拉取最新 stock_data（最近 5 日）+ 最新财务数据
2. 逐条检查证伪条件是否触发
3. 计算论文健康评分：**论文评分 = 初始 EV% × 时间衰减系数 × 条件存活率**
   - 时间衰减系数 = max(0.3, 1 - 已过天数 / (timeframe_months × 30))
   - 条件存活率 = 存活条件数 / 总条件数
   - 评分 > 3% → 🟢 健康 | 1-3% → 🟡 预警 | < 1% → 🔴 濒死
4. 将本次 review（日期、评分、当前价、浮动盈亏、条件检查结果）写入 thesis_ledger.json 的 reviews 数组

输出总览表：

```
┌─────────────────────────────────────────────────────┐
│  THESIS LEDGER — 2026-06-01 复盘                      │
├────┬────────┬──────┬──────┬────────┬──────┬──────────┤
│ ID │ 标的   │ 入场 │ 现价 │ 浮动盈亏│ 状态 │ 证伪触发？│
├────┼────────┼──────┼──────┼────────┼──────┼──────────┤
│001 │万华化学│75.70 │76.50 │ +1.1%  │🟢ACT │ 无       │
│002 │环旭电子│40.34 │39.80 │ -1.3%  │🟡WARN│ 条件①疑  │
└────┴────────┴──────┴──────┴────────┴──────┴──────────┘

累计统计：
├── 总论文数：2
├── ACTIVE：2
├── PASSED：0
├── FAILED：0
└── 命中率：N/A（尚无关闭的论文）
```

如果发现证伪条件已触发，标红并询问用户是否关闭。

### 模式三：/thesis close <THESIS-ID>

关闭一条论文。先读取该论文的数据，拉取最新行情，计算最终盈亏，标记为 PASSED 或 FAILED。

判定规则：
- 触发止损 → FAILED
- 达到目标价 → PASSED
- 证伪条件触发 → FAILED
- 持有期满但未达目标 → 按实际盈亏判定
- 用户主动平仓 → 按实际盈亏判定

更新 thesis_ledger.json 中的状态和关闭信息。

展示关闭总结：

```
THESIS-001 已关闭：PASSED ✅
万华化学 600309
入场：¥75.70  出场：¥83.50
持有：94天  收益：+10.3%
论文验证：MDI价格上涨+12%，Q2营收跌幅收窄至-1.5%，高管继续增持
```

**然后立即写入 AI 跟踪记录：** 读取 `~/.claude/ai_track_record.json`，追加一条记录：

```json
{
  "date": "关闭日期",
  "type": "stock",
  "ticker": "600309.SH",
  "name": "万华化学",
  "recommendation": "BUY",
  "thesis_id": "THESIS-001",
  "entry_price": 75.70,
  "exit_price": 83.50,
  "return_pct": 10.3,
  "outcome": "correct",
  "days_held": 94,
  "source_command": "/thesis"
}
```

outcome 判定：
- 盈利 + 论文证伪条件未触发 → "correct"
- 亏损 + 证伪条件触发 → "correct"（论文预测了失败，也是对的）
- 盈利但证伪条件已触发 → "wrong"（论文逻辑错了，运气好赚了）
- 亏损且证伪条件未触发 → "wrong"（论文没能预测到亏损原因）

更新 ai_track_record.json 的 stats：
```
total_recommendations += 1
correct/wrong/pending 相应调整
accuracy_pct = correct / (correct + wrong) × 100
```

## 重要规则

1. **概率加起来必须 = 100%，否则拒绝保存。**
2. **证伪条件必须是可观测、可度量的，不能用「感觉不对」「市场不好」这种模糊表述。**
3. **每次 /thesis review 都要用最新数据逐条检验证伪条件，不能敷衍。**
4. **EV 必须 > 0 才建议执行。如果 EV ≤ 0，明确告诉用户「这笔交易期望值为负，不建议入场」。**
5. **如果 thesis_ledger.json 不存在，自动创建空文件。**
6. **论文关闭时必须联动更新 `~/.claude/ai_track_record.json`**，outcome 按逻辑判定而非按盈亏判定：
   - 盈利 + 证伪未触发 → "correct"
   - 亏损 + 证伪已触发 → "correct"（论文预测了失败）
   - 盈利但证伪已触发 → "wrong"（运气好）
   - 亏损且证伪未触发 → "wrong"（论文有漏洞）
7. **止损设置经验（来自 THESIS-001 万华化学复盘）：**
   - 底部是一个区间，不是一个精确的点位
   - 周期股被市场风格抽血时，可以跌得比估值模型预测的更深
   - 建议止损设「连续3日收盘价低于止损线」才执行，而非盘中跌破即止损
   - 证伪条件比止损价更重要——条件未触发时应允许暂时浮亏
